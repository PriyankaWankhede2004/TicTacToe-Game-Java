# Tic-Tac-Toe Java

This is a simple Tic-Tac-Toe game built using Java Swing.

## Features
- 2-player game.
- Displays the winner or if the game is a tie.

## How to Run
1. Clone the repository.
2. Compile and run the tic_tac_toe.java file.

### Key Points:
- *Prerequisites*: Mention that Java should be installed to run the program.
- *Commands*:
   - To clone the repository to the local machine use git clone.
   - To compile the Java file use javac tic_tac_toe.java. 
   - To run the compiled Java program use java tic_tac_toe.
